# Экспериментальная lineage-модель и read-only границы MVP

Каждый тест сохраняет parent object, control/challenger, одну переменную, exposure/rotation history, snapshots, calculation version и decision. MVP читает рекламные кабинеты и создаёт локальные креативные материалы, но не изменяет бюджеты, ставки, настройки, статусы или публикацию. Это необходимо, чтобы причинный вывод оставался воспроизводимым, а автоматизация не могла незаметно изменить рекламную доставку.

Автоматическое управление кабинетами рассматривается только отдельным этапом после threat model, dry-run, двухступенчатого подтверждения и rollback-плана.
