# Бесплатная стратегия хранения медиа

Для постоянного контура без платёжной подписки портал не использует Cloudflare R2.

## Контур

- `cloudflare/pages/media/` — оптимизированные превью и небольшие web-assets, которые публикуются вместе с Cloudflare Pages.
- `cloudflare/pages/media/manifest.json` — публичный индекс медиа без токенов и приватных ссылок.
- GitHub Releases репозитория — оригиналы креативов, видео и ZIP-архивы; ссылки на assets добавляются в manifest вручную после проверки.
- D1 хранит только метаданные, хэши, тип, размер и ссылку на публичный asset; бинарные файлы в D1 не записываются.

## Ограничения

- Репозиторий публичный, поэтому этот вариант подходит только для материалов, которые разрешено публиковать.
- В бесплатном контуре нет пользовательских upload endpoints: загрузка выполняется через проверенный Git commit или Release.
- Не добавлять API-токены, signed URLs, cookies или приватные customer exports в Pages и GitHub.
- При переходе на платный object storage можно заменить resolver manifest на R2 без изменения доменной модели.

## Почему не R2

В текущем Cloudflare Dashboard R2 предлагает добавить подписку с автоматическим продлением и оплатой при превышении free allowance. Для требования «без оплаты» этот шаг не выполняется.
