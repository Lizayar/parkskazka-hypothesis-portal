# Единый портал журнала гипотез — Park Skazka

Спецификация аналитического портала для `parkskazka.com`. Портал объединяет рекламные данные, настройки и креативную историю по VK Ads, Яндекс Метрике, Авито Рекламе и Telegram Ads, а затем превращает наблюдения в ограниченные по сроку тесты с заранее заданными метриками и решением.

## Что проектируем

Портал состоит из пяти связанных контуров:

1. сбор и нормализация данных рекламных кабинетов и сайта;
2. единый обозреватель кампаний, групп, объявлений, креативов и настроек;
3. журнал гипотез с owner, сроком, baseline/control, primary и guardrail-метриками;
4. контроль ротаций креативов и наследования результата до компонента — hook, visual, copy, CTA, offer, landing;
5. ежедневная переоценка, уведомления и журнал решений.

## Канонический принцип

Каждое число должно отвечать на четыре вопроса: за какой период, из какого источника, на каком уровне объекта и по какой модели атрибуции оно рассчитано. Платформенные метрики и конверсии Метрики не смешиваются молча. Первичный результат теста — наблюдаемый эффект относительно control/baseline при пройденных gates качества и зрелости.
